# Escalas Top — canal público de atualizações

Este repositório é usado **somente para distribuir os pacotes binários oficiais de atualização** do Escalas Top.

- Não contém o código-fonte privado do sistema.
- Não contém tokens, senhas, credenciais do servidor ou dados de clientes.
- O sistema instalado consulta a Release mais recente e baixa o asset `escalastop-cpanel.zip`.
- A autoria e o desenvolvimento permanecem controlados no repositório privado do fornecedor.

A publicação das versões é automatizada e cada pacote é validado antes da Release.
