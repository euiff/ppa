🎵 Escala de Propósito + Holyrics

Sincronize as músicas do repertório do culto com a lista do Holyrics, mantendo a ordem cadastrada no Escala de Propósito.

1. Escolha a igreja

Cada igreja possui uma chave exclusiva. Somente Master ou administração da própria igreja pode criar ou revogar sua chave.

2. Instalar no computador da igreja

Instale o script uma única vez no Holyrics. Depois, em cada culto, basta selecionar o repertório.

  1. Atualize o Holyrics para a versão 2.23.0 ou superior.
  2. No Holyrics, abra Arquivo → Configurações → Avançado → JavaScript → Configurações → Requisições permitidas e libere https://escaladeproposito.com.br.
  3. Abra Ferramentas → Diversos → Script, crie um script chamado Escala de Propósito e cole o código do arquivo abaixo (substituindo o código de exemplo).
  4. Execute o script. Na primeira vez, cole a chave gerada acima. Ela ficará salva localmente nesse computador.
  5. Selecione o culto e confirme a importação. O Holyrics procurará as músicas na biblioteca que já existe nele.
Baixar script para Holyrics (.js)

O script não apaga a playlist atual e pede confirmação antes de adicionar as músicas. Músicas ausentes ou versões ambíguas precisam ser revisadas no Holyrics.

Como aparece no Holyrics?

Será um item com o nome Escala de Propósito em Scripts / Favoritos, com escolha de culto e repertório. Ele não aparecerá automaticamente em “Importar Lista Externa”, que depende de integração nativa aprovada pelos desenvolvedores do Holyrics.
